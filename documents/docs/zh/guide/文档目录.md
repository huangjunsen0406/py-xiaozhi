# py-xiaozhi文档目录

本目录包含了 py-xiaozhi 项目的全部功能文档，按功能模块进行划分，便于查阅和使用。

当前内置 MCP 工具聚焦于核心通用能力：系统音量控制、应用管理、摄像头（USB / 树莓派 CSI）与截屏视觉识别、天气查询；音乐、电台、播客、智能家居（HA）等扩展能力统一通过 **MCP 外挂插件**按需安装，宿主提供无音源依赖的通用媒体播放底座（`MediaPlayer` + `AudioMixer` + `AudioDecoder`）。

当前项目已启用 v2 授权协议，WSS 链接通过 OTA 接口返回，官方小智与开源后端均已对齐认证流程。

**角色定义加上：优先使用外部扩展工具（mcp\iot），不能偷懒不执行
这样就不会不执行mcp或者iot了，但是还是有概率触发系统相同的功能的工具，此时可能需要提示下它**
