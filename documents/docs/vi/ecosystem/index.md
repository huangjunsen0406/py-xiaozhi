# Hệ sinh thái liên quan

Tổng hợp và giới thiệu các dự án trong hệ sinh thái liên quan đến **py-xiaozhi**.

## Các dự án trong hệ sinh thái

| Dự án | Mô tả | Liên kết |
|------|------|------|
| **xiaozhi-esp32** | Phiên bản phần cứng ESP32 gốc của Xiaozhi | [GitHub](https://github.com/78/xiaozhi-esp32) |
| **xiaozhi-in-rdk** | Bản thích ứng chính thức của D-Robotics cho bo mạch RDK X3/X5/S100, tích hợp nhận diện vật thể YOLOv8 | [GitHub](https://github.com/D-Robotics/xiaozhi-in-rdk) |
| **xiaozhi-esp32-server** | Máy chủ backend Xiaozhi viết bằng Python, hỗ trợ tự triển khai kèm bảng điều khiển quản trị đầy đủ | [GitHub](https://github.com/xinnan-tech/xiaozhi-esp32-server) |
| **xiaozhi-esp32-server-java** | Máy chủ backend Xiaozhi viết bằng Java, nền tảng quản lý cấp doanh nghiệp hỗ trợ giám sát thiết bị, tùy chỉnh giọng nói và chuyển đổi vai trò | [GitHub](https://github.com/joey-zhou/xiaozhi-esp32-server-java) |
| **xiaozhi-server-go** | Máy chủ backend Xiaozhi viết bằng Go, phiên bản hiệu năng cao cho thương mại | [GitHub](https://github.com/AnimeAIChat/xiaozhi-server-go) |
| **xiaozhi-android-client** | Ứng dụng client cho Android, trò chuyện với Xiaozhi mọi lúc mọi nơi | [GitHub](https://github.com/TOM88812/xiaozhi-android-client) |
| **xiaozhi-unity** | Tích hợp vào Unity Engine, bổ sung khả năng tương tác giọng nói cho trò chơi | [GitHub](https://github.com/mainxx/xiaozhi-unity) |
| **IntelliConnect** | Giải pháp tích hợp nhà thông minh, kết nối thêm nhiều thiết bị IoT | [GitHub](https://github.com/peitaosu/IntelliConnect) |
| **open-xiaoai** | Giải pháp kết nối loa thông minh XiaoAI để biến loa thành thiết bị Xiaozhi | [GitHub](https://github.com/idootop/open-xiaoai) |

## Đóng góp dự án

Nếu bạn có dự án liên quan muốn chia sẻ với cộng đồng, hãy gửi Pull Request trên GitHub để bổ sung vào danh sách này.
