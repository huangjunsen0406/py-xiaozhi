# Cài đặt phụ thuộc hệ thống

## Tổng quan

Tài liệu này cung cấp hướng dẫn cài đặt đầy đủ các phụ thuộc cho dự án py-xiaozhi.

**Ngăn xếp công nghệ**:

- Python >= 3.10
- GUI: PySide6
- Trình quản lý gói: uv (khuyến nghị) / pip

### Lưu ý dành cho người dùng gói cài đặt

**Người dùng cài đặt qua gói phát hành chính thức (DMG / EXE / DEB) không cần tự cài đặt FFmpeg trên hệ thống.**

Gói cài đặt đã đóng gói sẵn bản di động của `ffmpeg` / `ffprobe` trong quá trình build (nằm tại `libs/ffmpeg/<platform>/<arch>/`), và ứng dụng sẽ ưu tiên sử dụng tệp nhị phân tích hợp khi chạy; âm thanh hướng dẫn kích hoạt cũng sử dụng tệp WAV dựng sẵn nên không phụ thuộc vào FFmpeg.

Hướng dẫn cài đặt phụ thuộc hệ thống bên dưới dành cho trường hợp **phát triển / chạy trực tiếp từ mã nguồn**.

## Phụ thuộc hệ thống

### Windows

```bash
# Cài đặt bằng Scoop (khuyến nghị) — cần cho giải mã âm thanh media/thông báo khi chạy từ mã nguồn
scoop install ffmpeg

# Hoặc dùng winget
winget install FFmpeg
```

**Bộ mã hóa/giải mã Opus**: Dự án đã đi kèm `opus.dll`, thông thường không cần cài đặt thêm. Nếu gặp lỗi, hãy sao chép `/libs/windows/opus.dll` vào thư mục ứng dụng hoặc `C:\Windows\System32`.

### macOS

```bash
# Cài đặt qua Homebrew
# Khi phát triển từ mã nguồn: portaudio / opus là bắt buộc; ffmpeg dùng để giải mã âm thanh media/thông báo chung (phát hướng dẫn kích hoạt không cần)
brew install portaudio opus ffmpeg

# Công cụ dòng lệnh Xcode
xcode-select --install
```

### Linux (Debian/Ubuntu)

> Tương thích với Ubuntu 20.04 / 22.04 / 24.04 / 25.04 và Raspberry Pi OS

Hãy chọn lệnh cài đặt tương ứng với phiên bản hệ điều hành của bạn. Tên gói ALSA và máy chủ âm thanh mặc định có thể khác nhau giữa các phiên bản.

**Kiểm tra phiên bản hệ điều hành**:

```bash
lsb_release -d  # Hoặc cat /etc/os-release
```

#### Ubuntu 22.04 (Khuyến nghị)

Máy chủ âm thanh mặc định: PipeWire (tương thích PulseAudio)

```bash
sudo apt-get update
sudo apt-get install -y \
    portaudio19-dev libportaudio2 \
    ffmpeg libopus0 libopus-dev \
    libasound2-dev \
    pulseaudio-utils \
    libxcb-xinerama0 libxkbcommon-x11-0 \
    build-essential python3-venv python3-pip
```

#### Ubuntu 24.04 / 25.04

Máy chủ âm thanh mặc định: PipeWire. Gói phát triển ALSA đã đổi tên thành `libasound-dev` (tên cũ `libasound2-dev` vẫn dùng được).

```bash
sudo apt-get update
sudo apt-get install -y \
    portaudio19-dev libportaudio2 \
    ffmpeg libopus0 libopus-dev \
    libasound-dev \
    pulseaudio-utils \
    libxcb-xinerama0 libxkbcommon-x11-0 \
    build-essential python3-venv python3-pip
```

#### Ubuntu 20.04

> Lưu ý: Ubuntu 20.04 mặc định dùng Python 3.8, cần cài đặt Python 3.10+ trước.

```bash
# 1. Cài đặt Python 3.10+
sudo add-apt-repository ppa:deadsnakes/ppa
sudo apt-get update
sudo apt-get install -y python3.10 python3.10-venv python3.10-dev

# 2. Cài đặt phụ thuộc âm thanh (máy chủ âm thanh mặc định: PulseAudio)
sudo apt-get install -y \
    portaudio19-dev libportaudio2 \
    ffmpeg libopus0 libopus-dev \
    libasound2-dev \
    pulseaudio-utils \
    build-essential
```

#### Raspberry Pi OS (Bookworm / Debian 12)

Bản Desktop đã cài sẵn PipeWire; bản Lite cần tự cài đặt máy chủ âm thanh.

```bash
sudo apt-get update

# Bản Desktop: PipeWire đã được cài sẵn, chỉ cần cài các gói phát triển
sudo apt-get install -y \
    portaudio19-dev libportaudio2 \
    ffmpeg libopus0 libopus-dev \
    libasound-dev \
    pulseaudio-utils \
    build-essential python3-venv python3-pip

# Bản Lite (không giao diện desktop) cài thêm máy chủ âm thanh:
# sudo apt-get install -y pipewire pipewire-pulse wireplumber
```

> Trên Raspberry Pi, khuyến nghị sử dụng card âm thanh USB vì cổng âm thanh 3.5mm tích hợp có chất lượng thấp và độ trễ cao.

#### Camera Raspberry Pi (Tùy chọn)

| Loại | Phụ thuộc | Ghi chú |
| ---- | ---- | ---- |
| USB UVC | OpenCV (đã có trong phụ thuộc dự án) + nhóm `video` | Cấu hình `CAMERA.device=/dev/videoX` hoặc `camera_index` tương ứng |
| Mô-đun CSI chính hãng | **Gói hệ thống** `python3-picamera2` | Ngăn xếp libcamera trên Bookworm; đặt `CAMERA.backend=auto` hoặc `picamera2` |

```bash
# USB / Chung
sudo usermod -aG video $USER
# Sau khi đăng nhập lại:
ls -l /dev/video*

# CSI chính hãng (chỉ dành cho Raspberry Pi, KHÔNG cài picamera2 bằng pip trên macOS)
sudo apt-get install -y python3-picamera2
# Nếu dùng venv và cần import gói hệ thống:
# python3 -m venv --system-site-packages .venv

# Kiểm tra
rpicam-hello -t 1000   # Hoặc libcamera-hello
python scripts/camera_scanner.py --test
```

> Xem chi tiết cấu hình và khắc phục sự cố tại [Công cụ Camera](../mcp/camera.md).

#### Quyền truy cập âm thanh

```bash
sudo usermod -a -G audio $USER
# Đăng nhập lại để có hiệu lực
```

#### Kiểm tra âm thanh

```bash
# Kiểm tra máy chủ âm thanh
pactl info | grep "Server Name"
# Kết quả mong đợi:
#   PulseAudio → "Server Name: pulseaudio"
#   PipeWire   → "Server Name: PulseAudio (on PipeWire x.x.x)"

# Kiểm tra thiết bị card âm thanh
aplay -l           # Liệt kê thiết bị đầu ra
arecord -l         # Liệt kê thiết bị đầu vào

# Kiểm tra PortAudio
python3 -c "import sounddevice; print(sounddevice.query_devices())"
```

> **Quan trọng**: Không cài đặt gói daemon `pulseaudio` trên hệ thống dùng PipeWire (Ubuntu 22.04+) vì sẽ gây xung đột với PipeWire. Chỉ cần cài `pulseaudio-utils` (cung cấp lệnh `pactl`).

## Cấu hình môi trường Python

### Cách 1: uv (Khuyến nghị)

[uv](https://github.com/astral-sh/uv) là trình quản lý gói Python hiện đại, tốc độ cao và tự động quản lý môi trường ảo.

**Cài đặt uv**:

```bash
# macOS / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows (PowerShell)
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

**Cài đặt phụ thuộc dự án**:

```bash
uv sync
```

**Chạy dự án**:

```bash
uv run python main.py
```

### Cách 2: pip + venv

```bash
# Tạo môi trường ảo
python3 -m venv .venv

# Kích hoạt môi trường ảo
source .venv/bin/activate      # Linux/macOS
# .venv\Scripts\activate       # Windows

# Cài đặt phụ thuộc
pip install -r requirements.txt
```

### Cách 3: Conda (Tùy chọn)

> Chỉ sử dụng khi cần các phụ thuộc C++ đặc biệt (như CUDA/MKL)

```bash
# Tạo môi trường
conda create -n py-xiaozhi python=3.10 -y
conda activate py-xiaozhi

# Cài đặt phụ thuộc
pip install -r requirements.txt
```

## Khắc phục sự cố

### Cài đặt SoundDevice thất bại

```bash
# Ubuntu 20.04 / 22.04
sudo apt-get install -y portaudio19-dev libasound2-dev libportaudio2

# Ubuntu 24.04+
sudo apt-get install -y portaudio19-dev libasound-dev libportaudio2

# macOS
brew install portaudio
```

### Không tìm thấy thiết bị âm thanh (Linux)

Thường gặp trên Raspberry Pi hoặc khi tự khởi động dưới dạng dịch vụ, do PortAudio khởi tạo trước khi dịch vụ âm thanh sẵn sàng dẫn đến danh sách thiết bị trống.

```bash
# 1. Xác nhận dịch vụ âm thanh đang chạy
pactl info

# 2. Nếu pactl báo lỗi, kiểm tra trạng thái dịch vụ âm thanh
systemctl --user status pipewire pipewire-pulse  # Hệ thống PipeWire
systemctl --user status pulseaudio               # Hệ thống PulseAudio

# 3. Nếu aplay -l thấy thiết bị nhưng Python không thấy, khởi động lại dịch vụ âm thanh
systemctl --user restart pipewire pipewire-pulse wireplumber

# 4. Bản Raspberry Pi Lite: có thể cần tự cài đặt máy chủ âm thanh
sudo apt-get install -y pipewire pipewire-pulse wireplumber
systemctl --user enable pipewire pipewire-pulse wireplumber
systemctl --user start pipewire pipewire-pulse wireplumber
```

### Xung đột giữa PulseAudio và PipeWire

Nếu lỡ cài nhầm daemon `pulseaudio` khiến âm thanh hoạt động bất thường:

```bash
# Gỡ bỏ daemon PulseAudio (giữ lại công cụ pactl)
sudo apt-get remove -y pulseaudio
sudo apt-get install -y pulseaudio-utils  # Chỉ cài công cụ dòng lệnh

# Khởi động lại PipeWire
systemctl --user restart pipewire pipewire-pulse wireplumber
```

### Lỗi import sherpa-onnx (macOS)

`sherpa-onnx` cần thư viện động `onnxruntime`, đôi khi có thể bị thiếu trên macOS:

```bash
# Tải xuống onnxruntime
cd /tmp
curl -sL "https://github.com/microsoft/onnxruntime/releases/download/v1.17.1/onnxruntime-osx-arm64-1.17.1.tgz" -o onnxruntime.tgz
tar -xzf onnxruntime.tgz

# Sao chép thư viện động vào sherpa_onnx
cp onnxruntime-osx-arm64-1.17.1/lib/libonnxruntime.1.17.1.dylib \
   .venv/lib/python3.10/site-packages/sherpa_onnx/lib/
```

## Đổi nguồn tải gói (Tùy chọn mirror)

### Đổi mirror cho pip

```bash
pip config set global.index-url https://mirrors.aliyun.com/pypi/simple/
```

### Đổi mirror cho uv

```bash
# Thiết lập biến môi trường
export UV_INDEX_URL=https://mirrors.aliyun.com/pypi/simple/

# Hoặc cấu hình trong pyproject.toml
# [tool.uv]
# index-url = "https://mirrors.aliyun.com/pypi/simple/"
```

## Yêu cầu phiên bản

| Phụ thuộc   | Phiên bản |
| ----------- | --------- |
| Python      | >= 3.10   |
| PySide6     | >= 6.6.0  |
| SoundDevice | >= 0.4.4  |
| FFmpeg      | >= 4.0    |
| Opus        | >= 1.3    |
| PortAudio   | >= 19.0   |

## Lưu ý

1. **Khuyến nghị dùng uv** để quản lý phụ thuộc vì tốc độ nhanh và tự động xử lý môi trường ảo
2. **Phiên bản Python**: Bắt buộc >= 3.10, không hỗ trợ 3.9 trở xuống
3. **Cài phụ thuộc hệ thống trước**: Khi chạy từ mã nguồn, hãy cài đặt phụ thuộc hệ thống (ffmpeg, opus, portaudio) trước khi cài đặt phụ thuộc Python
4. **Không trộn lẫn trình quản lý gói**: Chỉ chọn dùng uv hoặc pip, tránh dùng lẫn cả hai
5. **macOS sherpa-onnx**: Lần chạy đầu tiên có thể cần sao chép thủ công thư viện động `onnxruntime`
6. **Người dùng gói cài đặt không cần cài FFmpeg**: Gói phát hành đã tích hợp sẵn bản di động của ffmpeg/ffprobe; chỉ khi chạy từ mã nguồn cần phát thông báo hoặc plugin âm thanh mở rộng mới cần FFmpeg hệ thống hoặc đặt sẵn trong `libs/ffmpeg/`
7. **Raspberry Pi CSI**: Dùng `apt install python3-picamera2`, không cài `picamera2` bằng pip trên macOS / máy tính phát triển (vì phụ thuộc vào `python-prctl` chỉ khả dụng trên Linux)
