# Tính năng đánh thức bằng giọng nói

## Tổng quan

py-xiaozhi tích hợp tính năng đánh thức bằng giọng nói có độ chính xác cao dựa trên **Sherpa-ONNX**, hỗ trợ tùy chỉnh từ khóa đánh thức và phát hiện theo thời gian thực. Bằng cách sử dụng mô hình phát hiện từ khóa gọn nhẹ, hệ thống đạt tốc độ phản hồi ở mức mili-giây.

## Mô hình từ khóa đánh thức

### Mô hình tích hợp sẵn (dùng ngay)

Kho mã nguồn đã tích hợp sẵn mô hình phát hiện từ khóa Sherpa-ONNX trong hai thư mục `models/zh` và `models/en`, có thể sử dụng trực tiếp:

- `models/zh`: Mô hình tiếng Trung (`MODEL_PATH` mặc định), trong `keywords.txt` đã cài sẵn từ khóa đánh thức「小爱同学」, dùng kèm với `WAKE_WORD_LANG: "zh"`, hỗ trợ tự thêm các dòng phiên âm bính âm (pinyin) khác.
- `models/en`: Mô hình tiếng Anh (đơn vị BPE), `keywords.txt` mặc định chứa từ kích hoạt `MOSS`, dùng kèm với `WAKE_WORD_LANG: "en"`.
- Mỗi thư mục đều đã có sẵn `encoder.onnx`/`decoder.onnx`/`joiner.onnx`/`tokens.txt`/`keywords.txt`, có thể chạy ngay mà không cần tải thêm.
- Nếu muốn tùy chỉnh từ khóa đánh thức, chỉ cần chỉnh sửa tệp `keywords.txt` trong thư mục ngôn ngữ tương ứng, đồng thời chuyển đổi `MODEL_PATH` và `WAKE_WORD_LANG` trong `WAKE_WORD_OPTIONS`.

| Ngôn ngữ   | `MODEL_PATH` | `WAKE_WORD_LANG` | Từ kích hoạt mặc định trong `keywords.txt` | Giá trị `WAKE_WORD` mẫu |
| ---------- | ------------ | ---------------- | ------------------------------------------ | ----------------------- |
| Tiếng Trung | `models/zh`  | `zh`             | `小爱同学`                                 | `小爱同学`              |
| Tiếng Anh  | `models/en`  | `en`             | `MOSS`                                     | `MOSS`                  |

Khi chuyển đổi ngôn ngữ, vui lòng thực hiện đồng thời các bước sau:

1. Điều chỉnh `WAKE_WORD_OPTIONS.MODEL_PATH` trỏ tới thư mục ngôn ngữ mục tiêu;
2. Đặt `WAKE_WORD_OPTIONS.WAKE_WORD_LANG` thành `zh` hoặc `en`;
3. Cập nhật `WAKE_WORD_OPTIONS.WAKE_WORD` thành cụm từ đang có trong `keywords.txt` hiện tại (ví dụ `MOSS` hoặc `小爱同学`);
4. Nếu đã chỉnh sửa `keywords.txt`, hãy đảm bảo chính tả/pinyin của từ khóa đánh thức mới khớp với cấu hình, nếu không hệ thống sẽ không phát hiện được.

> Chỉ khi bạn muốn cập nhật phiên bản mô hình hoặc thay thế bằng tập huấn luyện khác thì mới cần tải lại tệp mô hình theo các bước bên dưới.

## Bật tính năng đánh thức bằng giọng nói

### Thiết lập tệp cấu hình

Chỉnh sửa `config/config.json`:

```json
{
  "WAKE_WORD_OPTIONS": {
    "USE_WAKE_WORD": true,
    "MODEL_PATH": "models/zh",
    "NUM_THREADS": 4,
    "PROVIDER": "cpu",
    "MAX_ACTIVE_PATHS": 2,
    "KEYWORDS_SCORE": 1.8,
    "KEYWORDS_THRESHOLD": 0.2,
    "NUM_TRAILING_BLANKS": 1,
    "WAKE_WORD": "小爱同学",
    "WAKE_WORD_LANG": "zh"
  }
}
```

Để chuyển sang từ khóa đánh thức tiếng Anh, chỉ cần đổi `MODEL_PATH` thành `models/en`, đổi `WAKE_WORD` thành `MOSS`, đồng thời đặt `WAKE_WORD_LANG` thành `en`. Dù chọn ngôn ngữ nào, `WAKE_WORD` cũng phải khớp với một dòng tương ứng trong `keywords.txt`.

### Chi tiết các tham số cấu hình

| Tham số               | Giá trị mặc định | Mô tả                                                        | Gợi ý tinh chỉnh                                |
| --------------------- | ---------------- | ------------------------------------------------------------ | ----------------------------------------------- |
| `USE_WAKE_WORD`       | `true`           | Bật tính năng đánh thức bằng giọng nói                       | -                                               |
| `MODEL_PATH`          | `"models/zh"`    | Thư mục chứa tệp mô hình                                     | Tiếng Trung dùng `models/zh`, tiếng Anh dùng `models/en` |
| `NUM_THREADS`         | `4`              | Số luồng xử lý                                               | Máy cấu hình mạnh có thể đặt 6-8                |
| `PROVIDER`            | `"cpu"`          | Động cơ suy luận                                             | Tùy chọn: cpu, cuda, coreml                     |
| `MAX_ACTIVE_PATHS`    | `2`              | Số đường tìm kiếm                                            | Giảm để tăng tốc độ, tăng để tăng độ chính xác  |
| `KEYWORDS_SCORE`      | `1.8`            | Điểm tăng cường từ khóa                                      | Tăng để giảm nhận nhầm, giảm để tăng độ nhạy    |
| `KEYWORDS_THRESHOLD`  | `0.2`            | Ngưỡng phát hiện                                             | Giảm để tăng độ nhạy, tăng để giảm nhận nhầm    |
| `NUM_TRAILING_BLANKS` | `1`              | Số khoảng trắng đệm ở cuối                                   | Thường giữ nguyên là 1                          |
| `WAKE_WORD`           | `"小爱同学"`     | Văn bản từ khóa đánh thức, dùng cho hiển thị UI và nhật ký   | Phải tồn tại trong `keywords.txt`               |
| `WAKE_WORD_LANG`      | `"zh"`           | Ngôn ngữ từ khóa đánh thức (`zh`/`en`)                       | Phải khớp với `MODEL_PATH`                      |

## Tùy chỉnh từ khóa đánh thức

### Cách khuyến nghị: Lưu nhanh một chạm trong cửa sổ Cài đặt

1. Mở giao diện desktop, vào **Cài đặt → Từ khóa đánh thức** (`src/ui/gui/qml/windows/settings/WakeWordTab.qml`).
2. Đánh dấu chọn "Bật từ khóa đánh thức", nhập trực tiếp cụm từ tiếng Trung hoặc tiếng Anh vào ô nhập liệu (ví dụ "你好小智" hoặc "Hey Moss").
3. Trong quá trình nhập, hệ thống sẽ hiển thị "Xem trước chuyển đổi" theo thời gian thực: bản tiếng Trung tự động chuyển sang pinyin, bản tiếng Anh sử dụng BPE tokens và gắn nhãn ngôn ngữ tương ứng.
4. Nhấn "Lưu từ khóa đánh thức", hệ thống sẽ gọi `convert_wake_word()` (`src/ui/shared/models/settings_model.py:314-365`):
   - Tự động nhận diện ngôn ngữ, cập nhật `WAKE_WORD`, `WAKE_WORD_LANG` và `MODEL_PATH`;
   - Ghi từ khóa được tạo vào thư mục tương ứng (`models/zh/keywords.txt` hoặc `models/en/keywords.txt`);
   - Giữ đồng bộ giữa tệp cấu hình và trạng thái trên UI.

> Cách này phù hợp cho kịch bản sử dụng 1 từ khóa đánh thức chính; khi lưu sẽ ghi đè nội dung của tệp `keywords.txt` đích. Nếu bạn cần giữ đồng thời nhiều từ khóa hoặc quản lý hàng loạt, hãy chuyển sang phần "Thêm thủ công" bên dưới.

### Các từ khóa đánh thức được hỗ trợ hiện tại

Kho mã nguồn cung cấp sẵn bộ từ khóa tiếng Trung và tiếng Anh đi kèm mô hình, có thể dùng ngay sau khi khởi chạy:

**Tiếng Trung (`models/zh/keywords.txt`)**

```
x iǎo ài t óng x ué @小爱同学
```

> Đặt `WAKE_WORD` thành `小爱同学` và `WAKE_WORD_LANG` thành `zh` là có thể đánh thức trực tiếp; nếu bạn thêm từ tùy chỉnh như "中国好助手", cũng cần cập nhật đồng bộ hai mục này.

**Tiếng Anh (`models/en/keywords.txt`)**

```
▁MO S S @MOSS
```

> Từ khóa tiếng Anh sử dụng SentencePiece/BPE tokens của Sherpa-ONNX, ký tự `▁` ở đầu biểu thị vị trí đầu từ. Chỉ cần thiết lập `MODEL_PATH: "models/en"`, `WAKE_WORD: "MOSS"`, `WAKE_WORD_LANG: "en"` để sử dụng.

### Thêm từ khóa đánh thức thủ công (tùy chọn nâng cao)

#### Cách 1: Chỉnh sửa trực tiếp tệp từ khóa

Chỉnh sửa tệp tương ứng với ngôn ngữ đã chọn:

- **Tiếng Trung**: Chỉnh sửa `models/zh/keywords.txt`, mỗi dòng một từ khóa đánh thức theo định dạng "pinyin + `@` + nguyên văn";
- **Tiếng Anh**: Chỉnh sửa `models/en/keywords.txt`, mỗi dòng một từ khóa đánh thức dùng SentencePiece tokens (ví dụ: `▁HE L LO ▁X I AO ▁Z H I @HELLO XIAOZHI`). Khuyến nghị sử dụng script chuyển đổi của Sherpa-ONNX hoặc tham khảo ví dụ sẵn có để giữ đúng chữ hoa/thường và khoảng trắng.

```
# Định dạng: phân tách pinyin @nguyên văn tiếng Trung
x iǎo zh ì @小智
n ǐ h ǎo x iǎo zh ì @你好小智
j iā w éi s ī @贾维斯
k āi sh ǐ g ōng z uò @开始工作
```

> Sau khi chỉnh sửa xong, nhớ cập nhật `WAKE_WORD` thành văn bản từ khóa mới và kiểm tra `WAKE_WORD_LANG` khớp với thư mục mô hình, nếu không tính năng đánh thức sẽ không kích hoạt. Nếu sau đó bạn dùng lại nút "Lưu từ khóa đánh thức" trên giao diện cài đặt, tệp này sẽ bị ghi đè thành một dòng duy nhất.

#### Cách 2: Sử dụng công cụ chuyển đổi pinyin

```python
from pypinyin import lazy_pinyin, Style

def generate_keyword_line(text):
    pinyin_list = lazy_pinyin(text, style=Style.TONE3, neutral_tone_with_five=True)
    processed_pinyin = [py.rstrip('12345') for py in pinyin_list]
    pinyin_str = ' '.join(processed_pinyin)
    return f'{pinyin_str} @{text}'

# Tạo từ khóa đánh thức mới
wake_words = ['小助手', '开始工作', '星期五']
for word in wake_words:
    print(generate_keyword_line(word))
```

### Gợi ý chọn từ khóa đánh thức

#### Đặc điểm của từ khóa đánh thức tốt

- **Độ dài vừa phải**: 2–4 âm tiết/ký tự
- **Phát âm rõ ràng**: Tránh các âm tương tự dễ gây nhầm lẫn
- **Tính đặc trưng cao**: Tránh các từ thường dùng trong giao tiếp hằng ngày
- **Dễ đọc, dễ nhớ**: Thuận miệng khi phát âm

#### Ví dụ từ khóa đánh thức tốt

```
- 你好小智    # 4 chữ, đặc trưng, rõ ràng
- 贾维斯      # 3 chữ, độc đáo, mang cảm giác công nghệ
- 开始工作    # 4 chữ, ý định rõ ràng
- 小助手      # 3 chữ, ngắn gọn dễ nhớ
```

#### Những từ nên tránh

```
- 嗯         # Quá ngắn, dễ kích hoạt nhầm
- 你好       # Quá phổ biến
- 请帮我做一个计划 # Quá dài
- 谢谢       # Câu nói thông dụng hằng ngày
```


#### 2. Tốc độ phản hồi chậm

**Triệu chứng**: Độ trễ nhận diện từ khóa đánh thức lớn

```json

    "NUM_THREADS": 6,            // Tăng số luồng

  }
}
```

#### 3. Nhận nhầm thường xuyên

**Triệu chứng**: Hệ thống hay tự kích hoạt đánh thức ngoài ý muốn

**Giải pháp**:

```json
{

    "KEYWORDS_SCORE": 2.5,       // Tăng điểm
```


## Cấu hình nâng cao

### Thích nghi với môi trường

#### Môi trường yên tĩnh (văn phòng)

```json
{
  "WAKE_WORD_OPTIONS": {
    "KEYWORDS_THRESHOLD": 0.15,
    "KEYWORDS_SCORE": 1.5,
    "MAX_ACTIVE_PATHS": 1
  }
}
```

#### Môi trường ồn ào (không gian mở)

```json
{
  "WAKE_WORD_OPTIONS": {
    "KEYWORDS_THRESHOLD": 0.25,
    "KEYWORDS_SCORE": 2.5,
    "MAX_ACTIVE_PATHS": 3
  }
}
```

### Tích hợp với AEC

Tính năng đánh thức bằng giọng nói tích hợp liền mạch với khử tiếng vọng âm thanh (AEC):

```json
{
  "AEC_OPTIONS": {
    "ENABLED": true,              // AEC cung cấp tín hiệu âm thanh sạch cho bộ phát hiện từ khóa
    "ENABLE_PREPROCESS": true     // Giảm nhiễu giúp nâng cao độ chính xác nhận diện
  },
  "WAKE_WORD_OPTIONS": {
    "USE_WAKE_WORD": true         // Sử dụng âm thanh sau khi đã qua xử lý AEC
  }
}
```

### Chỉ số hiệu năng tham chiếu

Hiệu năng kỳ vọng với cấu hình tiêu chuẩn:

| Chỉ số                     | Giá trị mục tiêu | Mô tả                                            |
| -------------------------- | ---------------- | ------------------------------------------------ |
| **Độ trễ phản hồi**        | < 1 giây         | Từ lúc nói xong đến khi hoàn tất phát hiện       |
| **Độ chính xác phát hiện** | > 95%            | Nhận diện chính xác từ khóa đánh thức đã đặt     |
| **Tỷ lệ nhận nhầm**        | < 5%             | Tần suất kích hoạt sai                           |
| **Mức sử dụng CPU**        | < 30%            | Tài nguyên tiêu thụ khi chạy liên tục            |
| **Mức sử dụng bộ nhớ**     | < 100MB          | Bộ nhớ cho mô hình và vùng đệm                   |
