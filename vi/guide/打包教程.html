Hướng dẫn đóng gói dự án ​

Tổng quan ​

UnifyPy 2.0 là công cụ đóng gói ứng dụng Python đa nền tảng, hỗ trợ đóng gói dự án Python thành gói cài đặt gốc cho Windows (EXE), macOS (DMG) và Linux (DEB).

Tính năng cốt lõi: Trình hướng dẫn cấu hình tương tác, xử lý đường dẫn thông minh, quản lý quyền tự động, biên dịch song song và hệ thống khôi phục (rollback).

📚 Tài liệu đầy đủ: Kho GitHub UnifyPy

Chuẩn bị môi trường ​

1. Cài đặt các gói phụ thuộc của dự án ​

bash
# Chuyển vào thư mục dự án
cd /path/to/py-xiaozhi

# Cài đặt gói phụ thuộc của dự án
pip install -r requirements.txt        # Windows/Linux
pip install -r requirements_mac.txt    # macOS

2. Cài đặt UnifyPy ​

bash
pip install unifypy

3. Công cụ riêng theo từng nền tảng ​

Nền tảng Windows ​

Cài đặt Inno Setup (dùng để tạo bộ cài đặt)

  • Sau khi cài đặt, cấu hình đường dẫn trong build.json hoặc đặt biến môi trường INNO_SETUP_PATH

Nền tảng macOS ​

  • Không cần cài đặt thêm (UnifyPy đã tích hợp sẵn công cụ create-dmg)

Nền tảng Linux ​

Cài đặt công cụ đóng gói:

bash
# Công cụ đóng gói định dạng DEB
sudo apt-get install dpkg-dev fakeroot

Cài đặt môi trường biên dịch (quan trọng):

bash
# Cài đặt công cụ và thư viện phát triển (cần cho NumPy và các gói phụ thuộc khác)
sudo apt update
sudo apt install -y build-essential python3-dev python3-pip python3-setuptools \
    libopenblas-dev liblapack-dev gfortran patchelf autoconf automake \
    libtool cmake libssl-dev libatlas-base-dev

# Cài đặt hệ thống build
pip install meson ninja
sudo apt install -y meson ninja-build

Cấu hình môi trường biên dịch NumPy:

bash
# Thiết lập biến môi trường
export BLAS=openblas
export LAPACK=openblas
export NPY_NUM_BUILD_JOBS=$(nproc)

# Kiểm tra NumPy hoạt động bình thường
python -c "import numpy; print('NumPy version:', numpy.__version__)"

Mẹo: Khuyến nghị sử dụng môi trường conda để tránh phần lớn các lỗi biên dịch:

bash
conda create -n build_env python=3.9
conda activate build_env
conda install numpy scipy openblas-devel
pip install unifypy

Nhúng FFmpeg trước khi đóng gói (bắt buộc) ​

Thư mục libs/ffmpeg/ đã được liệt kê trong .gitignore và không phân phối kèm kho mã nguồn. Trước khi đóng gói, bạn bắt buộc phải nhúng bản ffmpeg/ffprobe di động (portable), nếu không người dùng trên máy chưa cài FFmpeg hệ thống sẽ không thể giải mã luồng media tổng quát hay âm thanh thông báo.

Cấm dùng cp $(which ffmpeg) để sao chép tệp nhị phân liên kết động từ Homebrew / apt / choco — khi chạy trên máy người dùng sạch sẽ bị thiếu dylib/so và gây lỗi.

Script một lệnh (khuyến nghị) ​

bash
cd /path/to/py-xiaozhi

# macOS: cài đặt static-ffmpeg trước (trích xuất tệp nhị phân tích hợp, không dùng ffmpeg của brew)
uv pip install static-ffmpeg   # hoặc: pip install static-ffmpeg

# Tự động phát hiện nền tảng máy hiện tại, hoặc chỉ định rõ:
./scripts/bundle_ffmpeg.sh              # Tự động phát hiện
./scripts/bundle_ffmpeg.sh mac arm64    # mac Apple Silicon
./scripts/bundle_ffmpeg.sh win x64      # Windows
./scripts/bundle_ffmpeg.sh linux x64    # Linux x86_64
./scripts/bundle_ffmpeg.sh linux arm64  # Linux ARM64

# Kiểm tra kết quả
ls -lh libs/ffmpeg/*/
# Kiểm tra bổ sung trên mac: không được liên kết tới /opt/homebrew
otool -L libs/ffmpeg/mac/arm64/ffmpeg | grep -E 'homebrew|Cellar' && echo FAIL || echo OK

Script sẽ tải xuống hoặc trích xuất bản dựng có thể phân phối và ghi vào:

text
libs/ffmpeg/<plat>/<arch>/ffmpeg[.exe]
libs/ffmpeg/<plat>/<arch>/ffprobe[.exe]

Đồng thời chạy kiểm thử nhanh -version trong môi trường PATH cô lập; nếu thất bại sẽ thoát với mã khác 0.

Tiến hành đóng gói ​

bash
unifypy . --config build.json --clean

build.json / PyInstaller đã bao gồm thư mục dữ liệu libs, nên các tệp nhị phân vừa nhúng sẽ tự động được đóng gói vào bộ cài đặt.

Bắt đầu nhanh ​

Cách 1: Trình hướng dẫn tương tác (khuyến nghị cho lần đầu) ​

bash
# Khởi chạy trình hướng dẫn cấu hình trong thư mục dự án
cd /path/to/py-xiaozhi
unifypy . --init

Trình hướng dẫn sẽ dẫn dắt bạn hoàn tất:

  1. Cấu hình thông tin cơ bản (tên, phiên bản, tệp khởi chạy)
  2. Chọn nền tảng mục tiêu (Windows/macOS/Linux)
  3. Cấu hình PyInstaller (chế độ một tệp / cửa sổ, thư mục dữ liệu)
  4. Cấu hình đặc thù theo nền tảng (quyền truy cập, biểu tượng, tùy chọn cài đặt)
  5. Tự động tạo build.json và cho phép chọn build ngay lập tức

Cách 2: Sử dụng cấu hình có sẵn ​

Dự án đã có sẵn tệp build.json được cấu hình trước. Hãy nhúng FFmpeg trước (xem mục trên), sau đó tiến hành đóng gói:

bash
# 1) Nhúng ffmpeg/ffprobe di động
./scripts/bundle_ffmpeg.sh

# 2) Đóng gói
# Đóng gói cơ bản
unifypy . --config build.json

# Dọn dẹp và build lại từ đầu
unifypy . --config build.json --clean

# Hiển thị nhật ký chi tiết (khuyến nghị)
unifypy . --config build.json --verbose

# Chỉ tạo tệp thực thi
unifypy . --config build.json --skip-installer

# Build song song nhiều định dạng
unifypy . --config build.json --parallel --max-workers 4

Lệnh đóng gói theo từng nền tảng ​

Windows ​

bash
unifypy . --config build.json

Đầu ra:

  • Tệp thực thi: dist/xiaozhi/
  • Bộ cài đặt: dist/installer/xiaozhi-1.0.0-setup.exe

macOS ​

bash
# Chế độ phát triển (tự động cấu hình quyền)
unifypy . --config build.json --development

# Chế độ sản xuất
unifypy . --config build.json

Đầu ra:

  • Gói ứng dụng: dist/xiaozhi/XiaoZhi.app
  • Ảnh đĩa: dist/installer/xiaozhi-1.0.0.dmg

Linux ​

bash
unifypy . --config build.json

Đầu ra:

  • Tệp thực thi: dist/xiaozhi/
  • Gói cài đặt DEB: dist/installer/xiaozhi-1.0.0.deb

Lưu ý đặc biệt cho nền tảng Linux ​

Lỗi biên dịch NumPy ​

Triệu chứng: Xuất hiện lỗi biên dịch, thiếu thư viện BLAS/LAPACK, v.v.

Giải pháp:

bash
# Cách 1: Kiểm tra và cài đặt các thư viện phát triển còn thiếu
sudo apt install -y libopenblas-dev liblapack-dev gfortran

# Cách 2: Dùng gói wheel đã biên dịch sẵn (khuyến nghị)
pip install numpy --force-reinstall

# Cách 3: Đặt biến môi trường rồi cài đặt lại
export BLAS=openblas
export LAPACK=openblas
export NPY_NUM_BUILD_JOBS=4
pip install numpy --no-cache-dir

# Cách 4: Dùng môi trường conda (ổn định nhất)
conda install numpy scipy openblas-devel

Tương thích gói phụ thuộc ​

Chương trình sau khi đóng gói không chạy được trên hệ thống Linux khác?

Giải pháp: Biên dịch trên bản phân phối Linux đời cũ hơn, khuyến nghị dùng:

  • Ubuntu 18.04 LTS hoặc 20.04 LTS
  • CentOS 7

Hoặc sử dụng liên kết tĩnh:

bash
pip install staticx

Câu hỏi thường gặp ​

Q1: Lần đầu sử dụng không biết cấu hình ra sao? ​

bash
unifypy . --init  # Sử dụng trình hướng dẫn tương tác

Q2: Đóng gói thất bại? ​

bash
# Dọn dẹp rồi thử lại, bật xuất nhật ký chi tiết
unifypy . --config build.json --clean --verbose

Q3: Gặp vấn đề cấu hình quyền trên macOS? ​

bash
# Dùng chế độ phát triển để tự động sinh tệp quyền
unifypy . --config build.json --development --verbose

Q4: Xung đột gói phụ thuộc? ​

bash
# Tạo một môi trường thống nhất
conda create -n packaging python=3.9
conda activate packaging
pip install unifypy
pip install -r requirements.txt

Q5: Không tìm thấy đường dẫn trong tệp cấu hình? ​

UnifyPy 2.0 sử dụng cơ chế xử lý đường dẫn thông minh: mọi đường dẫn tương đối trong tệp cấu hình sẽ tự động được phân giải thành đường dẫn tuyệt đối tính từ thư mục dự án.

Ví dụ:

json
{
  "icon": "assets/icon.png"  // Tự động phân giải thành /path/to/project/assets/icon.png
}

Tính năng nâng cao ​

Hệ thống khôi phục (Rollback) ​

bash
# Liệt kê các phiên khôi phục hiện có
unifypy . --list-rollback

# Khôi phục về một phiên chỉ định
unifypy . --rollback SESSION_ID

Build song song ​

bash
# Build song song nhiều định dạng
unifypy . --config build.json --parallel --max-workers 4

Tự động quản lý quyền trên macOS ​

UnifyPy tự động tạo entitlements.plist và cập nhật Info.plist:

bash
# Chế độ phát triển (bao gồm quyền gỡ lỗi)
unifypy . --config build.json --development

# Chế độ sản xuất (chỉ giữ quyền cần thiết)
unifypy . --config build.json --production

Thông tin thêm ​

  • Tài liệu cấu hình đầy đủ: Xem UnifyPy README
  • Ví dụ cấu hình nâng cao: Tham khảo tệp build_comprehensive.json trong kho mã nguồn
  • Tham số PyInstaller: Tham khảo Tài liệu chính thức PyInstaller

Thực hành tốt nhất ​

  1. Quản lý môi trường: Dùng conda để tạo môi trường riêng dành cho việc đóng gói
  2. Lần đầu sử dụng: Dùng trình hướng dẫn --init để tạo cấu hình nhanh chóng
  3. Gỡ lỗi khi build: Luôn bật tham số --verbose
  4. Dọn sạch bản dựng: Định kỳ dùng --clean để đảm bảo bản dựng sạch sẽ
  5. Đóng gói trên Linux: Build trên Ubuntu 18.04/20.04 để đảm bảo khả năng tương thích
  6. Đóng gói trên macOS: Dùng chế độ --development trong giai đoạn phát triển
  7. Nhúng FFmpeg: Chạy ./scripts/bundle_ffmpeg.sh trước mỗi lần đóng gói sạch; không đưa libs/ffmpeg/ vào kho Git
