Hướng dẫn phím tắt ​

Tổng quan ​

py-xiaozhi hỗ trợ đầy đủ phím tắt toàn cục, cho phép thao tác nhanh ngay cả khi ứng dụng đang chạy nền. Hệ thống phím tắt được xây dựng trên thư viện pynput và hoạt động đa nền tảng.

Chi tiết từng phím tắt ​

Phím tắt tương tác giọng nói ​

Ctrl+J - Giữ để nói ​

  • Chức năng: Chế độ nhấn giữ thủ công, ghi âm trong lúc giữ phím
  • Cách sử dụng:
    1. Nhấn giữ Ctrl+J
    2. Nói vào micrô
    3. Thả phím để tự động gửi giọng nói
  • Tình huống phù hợp: Kiểm soát chính xác thời lượng ghi âm, tránh nhiễu tạp âm xung quanh

Ctrl+K - Hội thoại tự động ​

  • Chức năng: Bật/tắt chế độ hội thoại tự động
  • Cách sử dụng: Nhấn Ctrl+K để chuyển đổi trạng thái hội thoại tự động
  • Tình huống phù hợp: Hội thoại liên tục, tương tác trong thời gian dài

Ctrl+Q - Ngắt hội thoại ​

  • Chức năng: Dừng ngay phản hồi giọng nói hiện tại của AI
  • Cách sử dụng: Nhấn Ctrl+Q trong lúc AI đang trả lời
  • Tình huống phù hợp: Khi cần ngắt lời AI ngay lập tức

Phím tắt điều khiển chế độ ​

Ctrl+M - Chuyển chế độ tương tác ​

  • Chức năng: Chuyển đổi giữa các chế độ tương tác giọng nói
  • Cách sử dụng: Nhấn Ctrl+M để chuyển vòng tròn giữa các chế độ
  • Các chế độ: Chế độ nhấn giữ thủ công ↔ Chế độ hội thoại tự động

Ctrl+W - Hiện/Ẩn cửa sổ ​

  • Chức năng: Điều khiển trạng thái hiển thị của cửa sổ chính
  • Cách sử dụng: Nhấn Ctrl+W để chuyển đổi ẩn/hiện cửa sổ
  • Tình huống phù hợp: Ẩn hoặc hiện nhanh giao diện chính

Cấu hình phím tắt ​

Vị trí tệp cấu hình ​

Cấu hình phím tắt được lưu trong tệp config/config.json:

json
{
  "SHORTCUTS": {
    "ENABLED": true,
    "MANUAL_PRESS": {
      "modifier": "ctrl",
      "key": "j",
      "description": "Giữ để nói"
    },
    "AUTO_TOGGLE": {
      "modifier": "ctrl",
      "key": "k",
      "description": "Hội thoại tự động"
    },
    "ABORT": {
      "modifier": "ctrl",
      "key": "q",
      "description": "Ngắt hội thoại"
    },
    "MODE_TOGGLE": {
      "modifier": "ctrl",
      "key": "m",
      "description": "Chuyển chế độ"
    },
    "WINDOW_TOGGLE": {
      "modifier": "ctrl",
      "key": "w",
      "description": "Hiện/Ẩn cửa sổ"
    }
  }
}

Tùy chỉnh phím tắt ​

Phím bổ trợ được hỗ trợ ​

  • ctrl - Phím Ctrl
  • alt - Phím Alt
  • shift - Phím Shift
  • ctrl+alt - Tổ hợp Ctrl+Alt
  • ctrl+shift - Tổ hợp Ctrl+Shift

Phím chính được hỗ trợ ​

  • Phím chữ cái: a-z
  • Phím chữ số: 0-9
  • Phím chức năng: f1-f12
  • Phím đặc biệt: space, enter, tab, esc

Ví dụ cấu hình ​

json
{
  "SHORTCUTS": {
    "ENABLED": true,
    "MANUAL_PRESS": {
      "modifier": "alt",
      "key": "space",
      "description": "Giữ để nói"
    },
    "AUTO_TOGGLE": {
      "modifier": "ctrl+shift",
      "key": "a",
      "description": "Hội thoại tự động"
    }
  }
}

Khả năng tương thích nền tảng ​

Windows ​

  • Hỗ trợ đầy đủ: Mọi phím tắt hoạt động bình thường
  • Yêu cầu quyền: Một số trường hợp có thể cần quyền quản trị viên
  • Lưu ý: Tránh đặt trùng với phím tắt hệ thống

macOS ​

  • Cấu hình quyền: Cần cấp quyền Trợ năng (Accessibility)
  • Đường dẫn thiết lập: Cài đặt hệ thống (System Settings) → Quyền riêng tư & Bảo mật (Privacy & Security) → Trợ năng (Accessibility)
  • Quyền Terminal: Nếu chạy từ Terminal, cần cấp quyền cho ứng dụng Terminal

Linux ​

  • Nhóm người dùng: Cần thêm người dùng vào nhóm input
  • Lệnh cấu hình: sudo usermod -a -G input $USER
  • Môi trường desktop: Hỗ trợ X11 và Wayland

Khắc phục sự cố ​

Phím tắt không phản hồi ​

Kiểm tra cấu hình ​

  1. Xác nhận SHORTCUTS.ENABLED trong tệp cấu hình là true
  2. Kiểm tra định dạng cấu hình phím tắt đã hợp lệ chưa
  3. Kiểm tra phím bổ trợ và phím chính có hợp lệ không

Vấn đề về quyền ​

bash
# macOS: Kiểm tra quyền Trợ năng (Accessibility)
# Cài đặt hệ thống → Quyền riêng tư & Bảo mật → Trợ năng

# Linux: Thêm người dùng vào nhóm input
sudo usermod -a -G input $USER

# Windows: Chạy với quyền quản trị viên
# Nhấp chuột phải vào ứng dụng → Run as administrator

Kiểm tra xung đột ​

  1. Kiểm tra xem có ứng dụng khác đang dùng cùng tổ hợp phím tắt không
  2. Thử đổi sang tổ hợp phím tắt ít phổ biến hơn
  3. Đóng các ứng dụng có khả năng gây xung đột

Xử lý các lỗi thường gặp ​

ImportError: No module named 'pynput' ​

bash
# Cài đặt thư viện pynput
pip install pynput

macOS bị từ chối quyền ​

bash
# Kiểm tra và cấp quyền lại:
# Cài đặt hệ thống → Quyền riêng tư & Bảo mật → Trợ năng
# Gỡ ứng dụng khỏi danh sách rồi thêm lại

Lỗi lắng nghe bàn phím trên Linux ​

bash
# Thêm vào nhóm input rồi đăng nhập lại để áp dụng
sudo usermod -a -G input $USER
# Đăng xuất và đăng nhập lại

Cấu hình nâng cao ​

Cơ chế khôi phục lỗi ​

Hệ thống tích hợp sẵn cơ chế tự khôi phục lỗi cho phím tắt:

  • Kiểm tra định kỳ: Kiểm tra trạng thái bộ lắng nghe mỗi 30 giây
  • Tự động khởi động lại: Tự khởi động lại khi phát hiện bộ lắng nghe ngừng hoạt động
  • Đếm lỗi: Kích hoạt khôi phục khi số lỗi liên tiếp vượt ngưỡng
  • Dọn dẹp trạng thái: Xóa sạch trạng thái phím đang giữ khi khởi động lại

Chế độ gỡ lỗi ​

Bật xuất nhật ký chi tiết:

python
# Bật nhật ký gỡ lỗi cho pynput
import logging
logging.getLogger('pynput').setLevel(logging.DEBUG)

Tối ưu hiệu năng ​

  • Bộ đệm phím: Giảm việc phát hiện trùng lặp khi nhấn phím
  • Xử lý bất đồng bộ: Xử lý sự kiện phím không gây chặn luồng
  • Quản lý tài nguyên: Tự động giải phóng tài nguyên bộ lắng nghe

Tham chiếu mã nguồn ​

Vị trí triển khai hệ thống phím tắt:

  • Triển khai chính: src/plugins/shortcuts/
  • Quản lý cấu hình: src/utils/config_manager.py
  • Tích hợp ứng dụng: src/application.py

Phương thức cốt lõi ​

python
# Khởi động lắng nghe phím tắt
from src.plugins.shortcuts import ShortcutsPlugin
shortcuts_plugin = ShortcutsPlugin()

# Dừng lắng nghe thủ công
await shortcuts_plugin.stop()
